# Tech-Debt-Audit Skill

## Instructions
1. Scan the codebase or specific files for:
   - Long functions/classes.
   - Deep nesting.
   - Duplicated logic.
   - Tight coupling.
2. Identify violations of SOLID, DRY, and KISS.
3. Categorize issues by severity (Low, Medium, High).
4. Suggest specific refactoring steps.

## Guidelines
- Focus on maintainability.
- Don't suggest refactoring "working" code unless it's a high-risk area.
- Provide "Before" and "After" examples for clarity.
