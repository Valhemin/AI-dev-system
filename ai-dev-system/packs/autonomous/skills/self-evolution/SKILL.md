# Self-Evolution Skill

## Instructions
1. Observe friction points in the current workflow (e.g., missing skills, slow commands).
2. Propose a specific improvement to `ai-dev-system` (new script, updated rule, better template).
3. Implement the improvement in a separate branch or with user approval.
4. Run `ai-dev doctor` to ensure system integrity.

## Guidelines
- Do not break core CLI functionality.
- Keep the system portable and lean.
- Document every change in the system's own memory.
