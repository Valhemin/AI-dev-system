# PR-Architect Skill

## Instructions
1. Analyze the diff of changed files.
2. Summarize the "What" and "Why" of the changes.
3. Generate commit messages following Conventional Commits (e.g., `feat:`, `fix:`, `refactor:`).
4. Create a structured PR description with:
   - Summary
   - Type of change
   - Impact analysis
   - Verification steps performed.

## Guidelines
- Keep descriptions concise but informative.
- Highlight any breaking changes.
- Use emojis for readability if appropriate.
