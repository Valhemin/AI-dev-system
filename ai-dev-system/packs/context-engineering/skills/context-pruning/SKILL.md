# Context Pruning Skill

## Instructions
1. Review current conversation/context history.
2. Identify outdated information or resolved tasks.
3. Summarize key decisions and current state.
4. Suggest "forgetting" specific blocks to save tokens.
5. Maintain a "Golden Thread" of essential context.

## Guidelines
- Never prune active task requirements.
- Keep the latest error logs until resolved.
- Prioritize architectural decisions over implementation details.
