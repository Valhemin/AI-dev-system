# Advanced Reasoning (CoT) Skill

## Instructions
1. Break down the problem into atomic components.
2. State assumptions clearly.
3. Explore multiple solution paths (A, B, C).
4. Evaluate trade-offs for each path.
5. Select the optimal path and justify.

## Guidelines
- Think step-by-step.
- Explicitly look for edge cases.
- If a path leads to a dead end, backtrack and explain why.
