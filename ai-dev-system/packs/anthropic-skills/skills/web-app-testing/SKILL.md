# Web App Testing Skill

## Instructions
1. Analyze the web application structure.
2. Identify key user flows (login, checkout, etc.).
3. Write robust E2E tests using Playwright.
4. Handle asynchronous actions and wait for elements properly.
5. Generate clear reports on test failures.

## Guidelines
- Use Page Object Model (POM) for maintainability.
- Ensure tests are idempotent.
- Mock external APIs when necessary.
