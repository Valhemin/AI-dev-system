# Complex Data Analysis Skill

## Instructions
1. Load and inspect data schema/headers.
2. Identify missing values or anomalies.
3. Perform statistical analysis or transformations.
4. Generate insights and visualizations (using Python/Pandas if available).
5. Summarize findings for non-technical stakeholders.

## Guidelines
- Always verify data types before operations.
- Use vectorized operations for performance.
- Document every step of the transformation.
