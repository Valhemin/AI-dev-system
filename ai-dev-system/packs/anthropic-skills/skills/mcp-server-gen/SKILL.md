# MCP Server Generation Skill

## Instructions
1. Identify the data source or tool to be exposed via MCP.
2. Choose the appropriate SDK (TypeScript/Python).
3. Define resources, prompts, and tools clearly.
4. Implement secure authentication if required.
5. Provide installation and configuration instructions for the MCP client.

## Guidelines
- Follow the official MCP specification.
- Use descriptive names for tools and resources.
- Handle errors gracefully with clear error messages.
