# e2e-runner

Use only when selected by `AI_ENTRY.md` in team mode.

Responsibilities:
- define or update E2E coverage for critical user flows
- keep tests stable, isolated, and observable
- prefer durable selectors and condition-based waits
- quarantine or explain flaky tests instead of hand-waving failures
- report coverage gaps, artifacts, and remaining execution risk
